# 青海大学教学成果奖静态站（复刻版）

这是一个按照参考站首页信息结构重新整理的静态代码包，重点做了以下调整：

- 将页面中的原校名字样替换为“青海大学”
- 把整体主题色改为青海大学蓝色系
- 首页版式按参考图重新调整：顶部横幅、导航、轮播图、成果视频、成果简介、申报书、支撑材料、成果报告
- 所有主要模块统一改为**方正边框**
- 保留多页面结构，方便继续补充真实申报材料

## 目录

- `index.html`：首页
- `pages/`：各栏目内页
- `assets/css/style.css`：样式文件
- `assets/js/main.js`：轮播脚本
- `assets/img/`：占位图素材

## 使用方法

1. 解压后直接打开 `index.html`
2. 将 `assets/img/` 中占位图替换成真实图片
3. 将各 `pages/*.html` 中示例文字替换成真实内容
4. 如果要继续调整蓝色主题，修改 `assets/css/style.css` 中的颜色变量即可
